# **App Name**: RevivBali

## Core Features:

- Homepage: Replicates the original website's homepage with the same layout and design elements.
- Treatment Pages: Display of all treatments from revivme.com with corresponding images, descriptions and price information.
- Booking Feature: Implement a feature allowing users to book available services through an integrated booking form. Collect name, contact details, the option to leave notes, and display final total amount.
- Contact Page: A contact page with links for users to quickly get in contact

## Style Guidelines:

- Primary color: Deep Teal (#008080) for trustworthiness and a sense of well-being, taken from their webpage.
- Background color: Light Gray (#F0F0F0), for subtle contrast, cleanliness, and professionalism.
- Accent color: Sea Green (#3EA09B) as a complementary teal that fits with the website and draws user attention for primary CTAs.
- Font pairing: 'Poppins' (sans-serif) for headers to give a fashionable feel, and 'PT Sans' (sans-serif) for body text for readability.
- Use of clean and modern icons with rounded edges to enhance the user interface and align with the modern design aesthetic.
- Emulate the original layout from ReviveMe for a consistent replication. Make sure content has readable margins and doesn't fill the page
- Incorporate subtle animations on button hover states and page transitions to enhance interactivity.
